- Autocommit is a mode, by default is set to ON. Whenever u execute a transaction within mySQL, 
that transaction is saved automatically. If disabled the transaction can't be saved automatically.
Then we would need to manually save our transactions, creating safe points.

- A transaction in MySQL is a sequential group of statements, queries, or operations such as select, insert, update or delete 
to perform as a one single work unit that can be committed or rolled back. If the transaction makes multiple modifications 
into the database, two things happen:
    Either all modification is successful when the transaction is committed.
    Or, all modifications are undone when the transaction is rollback.
The transaction contains mainly four properties, which referred to as ACID property.
1. Atomicity:
This property ensures that all statements or operations within the transaction unit must be executed successfully. Otherwise, 
if any operation is failed, the whole transaction will be aborted, and it goes rolled back into their previous state.
2. Consistency: 
This property ensures that the database changes state only when a transaction will be committed successfully. 
It is also responsible for protecting data from crashes.
3. Isolation: 
This property guarantees that each operation in the transaction unit operated independently. 
It also ensures that statements are transparent to each other. 
4.Durability: 
This property guarantees that the result of committed transactions persists permanently even if the system crashes or failed. 
source - https://www.javatpoint.com/mysql-transaction


*** Commands ***

-- to disable Autocommit
SET AUTOCOMMIT = OFF;
SET AUTOCOMMIT = ON;

-- to manually save transaction and create a safe point
COMMIT;

-- to undo changes and go back to previous safe point
ROLLBACK;
